## How to use this

Since 3 August 2026, the Biometric Processing Privacy Code applies to all biometric processing in New Zealand, including systems that were running before the code. You need to be able to show your processing is justified. Use this worksheet alongside a [privacy impact assessment](/templates/privacy-impact-assessment/), and read the code and the Privacy Commissioner's guidance for the exact tests. This worksheet structures your evidence; it doesn't replace the code.
